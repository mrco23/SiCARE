# SiCARE UAT User Feedback Instrument

**Proyek:** SiCARE (Sistem Informasi Konseling & Rekam Terintegrasi)
**Dokumen:** Instrumen Evaluasi & Kuesioner Umpan Balik Pengguna (User Feedback Instrument)
**Tahap:** Batch 1.5g: Controlled User Acceptance Testing
**Tanggal:** 31 Oktober 2026
**Status Instrumen:** SIAP DIDISTRIBUSIKAN KE PENGUJI MANUSIA

---

## 1. Petunjuk Pengisian untuk Penguji

1. Kuesioner ini dirancang untuk menilai kenyamanan, kemudahan penggunaan (*usability*), dan kesiapan operasional sistem SiCARE dari sudut pandang pengguna langsung.
2. Pengisian kuesioner dilakukan secara mandiri oleh setiap penguji setelah menyelesaikan seluruh skenario uji pada perannya.
3. **Prinsip Kejujuran:** Berikan penilaian apa adanya sesuai pengalaman nyata Anda saat mengoperasikan aplikasi. Jangan ragu memberikan nilai rendah atau kritik membangun jika menemukan alur yang membingungkan atau sulit digunakan.
4. Skala Penilaian:
   - **1:** Sangat Sulit / Sangat Tidak Puas
   - **2:** Sulit / Tidak Puas
   - **3:** Cukup / Netral
   - **4:** Mudah / Puas
   - **5:** Sangat Mudah / Sangat Puas
