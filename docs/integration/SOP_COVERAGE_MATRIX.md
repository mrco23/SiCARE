# SiCARE SOP and Business Logic Coverage Matrix

**Snapshot audit:** `SiCARE(8).zip`, 29 Oktober 2026.

Matriks ini membedakan aturan yang sudah terlihat pada kode dari bagian yang masih membutuhkan implementasi atau konfirmasi SOP resmi. File ZIP tidak memuat satu dokumen SOP konseling formal yang lengkap. Karena itu, kolom “aturan yang terlihat” hanya merangkum kode dan dokumentasi yang tersedia, bukan menetapkan kebijakan klinis baru.

## Prioritas hasil audit

- **P0 tersisa:** jalankan live API smoke test dan verifikasi role. Migration history serta metadata tabel Hero pada Supabase sudah diverifikasi. Build, lint, backend check, dan seluruh 41 test backend sudah PASS. Jangan menyimpan atau mengklaim data consent/intake/tanda tangan/catatan konseling sebagai data backend sebelum model dan aturan akses resmi tersedia.
- **P1:** hubungkan periode, jadwal, profil konselor, keputusan booking, dan status sesi. Ini menutup siklus utama booking lintas-role.
- **P1:** hubungkan moderasi/review feedback, akun admin, dashboard, laporan, dan aktivitas audit.
- **P2:** profil/WhatsApp consent, mood tracker persistence bila dibutuhkan, dan penyelarasan wrapper API serta DTO.

Tidak ada request live ke Supabase yang dilakukan. Belum ada dokumen SOP formal lengkap di snapshot. Kriteria di atas harus disesuaikan jika pemilik proses menetapkan SOP tertulis yang berbeda.
